medical-assistant — v1 System Architecture

Patient-memory middle layer · Arabic-primary · on-prem / privacy-first · per spec/system-design.md (rev 2026-09-13)

Memory writer (ingestion)

  • • Audio → VAD → pyannote diarize → per-turn Cohere ASR (ar/en) → role pass → Turn records
  • • Rx photo → OCR draft → HITL confirm → formulary → ConfirmedPrescription (draft never surfaces)
  • • Lab sheets → panel text → LabResult records
  • • Scans / rx photos = ScanRecord metadata + source_turn FK, never embedded

Reader & generator

  • • CAG: active-session turns load directly into the prompt (deterministic, cached)
  • • /ask router: in-session = frame only; history = one tool → hybrid RAG
  • • Typed indexes: turns / lab_results / confirmed_rx (template-normalized) / scans
  • • bge-m3 hybrid ± enrichment + bge-reranker-v2-m3 + RRF
  • • Brief = long-context synthesis; summary tier = scale-escape-hatch, brief-only

Trust & audit

  • • Patient-granted, revocable AccessGrant scopes every read
  • • Every request = AuditEvent: context frame + ordered tool_call_seq
  • • Refusal is a typed contract; confirmed-data-only grounding
  • • On-prem for real data; dev-cloud synthetic-only; no cross-patient surface
